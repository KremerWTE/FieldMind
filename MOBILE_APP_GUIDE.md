
# FieldMind Mobile App - Field Worker Guide 📱

## Overview

The FieldMind mobile app is **optimized for construction workers and field technicians** to quickly capture, tag, and upload photos from job sites with minimal friction.

## Key Features for Field Workers

### 🎯 1. One-Tap Photo Capture
- **Large camera button** - Easy to tap even with gloves
- **Instant capture** - No complex menus
- **Batch mode** - Take multiple photos before uploading
- **Gallery import** - Select existing photos from phone

### 📍 2. GPS Auto-Tagging
- **Automatic location capture** - Every photo gets GPS coordinates
- **Nearby job sites** - App suggests sites based on your location
- **Distance display** - See how far you are from each site

### 🏢 3. Smart Job Site Selection
- **Recent sites first** - Quick access to sites you visit often
- **Nearby sites** - Shows closest buildings automatically
- **Simple search** - Find any site by name or address
- **No typing required** - Tap to select

### 🏷️ 4. Quick Tagging System
- **Pre-defined tags** - Common categories like "Roof", "Damage", "Water"
- **One-tap tagging** - No typing required
- **Multiple tags** - Tag each photo with as many categories as needed
- **Smart suggestions** - Based on AI analysis later

### 📁 5. Folder Organization
- **Quick folder creation** - Create folders on the fly
- **Tap to select** - Easy folder navigation
- **Visual organization** - See folder structure clearly

### 🔄 6. Offline Support
- **Queue uploads** - Photos saved locally if no connection
- **Auto-retry** - Uploads automatically when connection returns
- **Work anywhere** - No need for constant internet

### 🤖 7. AI Analysis Integration
- Photos are **automatically analyzed** after upload
- No extra steps required
- Results available in web dashboard

## Common Workflows

### Workflow 1: Daily Roof Inspection

**Scenario**: Technician inspects 3 buildings daily

1. **Morning - Building 1**
   - Open app → Recent Sites → Tap "Downtown Office"
   - Take 15 photos of roof sections
   - Quick tag: "Roof", "Exterior"
   - Upload all → AI analyzes automatically

2. **Midday - Building 2**
   - Recent Sites → Tap "Riverside Apartments"
   - Spot water damage
   - Take 5 photos
   - Tag: "Roof", "Damage", "Water"
   - Add note: "East corner, near HVAC"
   - Upload → Critical issue alert sent to PM

3. **Afternoon - Building 3**
   - Recent Sites → Tap last building
   - Take 10 completion photos
   - Tag: "Before", "After", "Roof"
   - Upload → Automatically added to project report

**Total time per building**: ~5 minutes including photos

### Workflow 2: Storm Damage Assessment

**Scenario**: Multiple buildings after storm

1. **Use Nearby Sites**
   - Nearby tab shows all buildings within 5km
   - Visit each building in order (closest first)

2. **Document Each Site**
   - Create new folder: "Storm Damage - [Date]"
   - Take comprehensive photos
   - Tag with severity: "Damage", "Critical", "Water"
   - Add specific notes for insurance

3. **Office Review**
   - PM receives critical alerts immediately
   - All photos auto-organized by building and folder
   - AI flags highest priority repairs
   - PDF report generated automatically

### Workflow 3: Client Walkthrough

**Scenario**: Show client progress on-site

1. **During Visit**
   - Take "Before" photos (if not done)
   - Take "After" photos showing completed work
   - Tag both: "Before", "After", location tags

2. **Immediate Share**
   - Photos upload while still on-site
   - PM creates share link from office
   - Client receives link via email
   - Can view progress gallery instantly

## Tag Recommendations

### By Location
- **Exterior**: Outside shots, siding, windows
- **Roof**: All roof-related photos
- **Interior**: Inside shots, rooms, ceilings
- **Foundation**: Basement, foundation walls
- **Attic**: Attic spaces, insulation

### By System
- **HVAC**: Heating, cooling, ventilation
- **Electrical**: Panels, wiring, outlets
- **Plumbing**: Pipes, fixtures, drains
- **Windows**: All window-related
- **Doors**: Entry, garage, interior doors

### By Condition
- **Damage**: Any type of damage found
- **Water**: Water intrusion, staining, moisture
- **Mold**: Suspected or visible mold
- **Crack**: Cracks in walls, foundation, etc.
- **Rust**: Rust or corrosion

### By Status
- **Before**: Before work begins
- **During**: Work in progress
- **After**: Completed work
- **Issue**: Problem found during inspection
- **Fixed**: Problem resolved

## Best Practices

### 📸 Photo Tips

**Good Lighting**
- Use natural light when possible
- Flash for dark interiors
- Multiple angles for context

**Clear Focus**
- Tap screen to focus on issue area
- Hold phone steady
- Get close enough to see details

**Context Shots**
- Take wide shot first (shows location)
- Then close-up of specific issue
- Include reference objects (ruler, hand) for scale

**Before/After**
- Same angle for both shots
- Same lighting conditions
- Tag appropriately

### 🏷️ Tagging Tips

**Be Consistent**
- Use the same tags for similar items
- Don't create duplicate tags ("Water" vs "water")
- Use pre-defined tags when possible

**Be Specific**
- Multiple tags better than one general tag
- "Roof" + "Damage" + "Shingle" > "Roof Damage"
- AI uses tags for better analysis

**Use Location Tags**
- Helps organize large buildings
- "North Side", "East Wing", "2nd Floor"
- Makes finding photos easier later

### 📁 Folder Organization

**By Type of Work**
- "Roof Inspection"
- "Interior Walkthrough"
- "Storm Damage Assessment"

**By Date**
- "Jan 2025 Monthly"
- "Q1 2025 Inspection"

**By Area**
- "Building A - East Side"
- "Unit 201-210"

### ⚡ Efficiency Tips

**Use Recent Sites**
- Recent sites load faster
- No scrolling needed
- GPS not required

**Batch Upload**
- Take all photos first

- Saves time and battery

**Work Offline**

## Troubleshooting

### "Can't Upload Photos"
1. Check internet connection
2. Photos will queue automatically
3. Upload when connection available

### "Location Not Working"
1. Settings → FieldMind → Location → Always
2. Restart app
3. Works without location, just no "Nearby" feature

### "Camera Not Opening"
1. Settings → FieldMind → Camera → Allow
2. Restart app
3. Use "Choose Photos" as alternative

### "Tags Not Saving"
1. Wait for upload to complete
2. Check upload queue
3. Tags saved locally until upload succeeds
