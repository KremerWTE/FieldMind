## Root Causes & Fixes

### 1. API job — CS0246 compile error

**File:** `apps/api/Controllers/ReportsController.cs`

**Error:**
```
error CS0246: The type or namespace name 'S3StorageService' could not be found
```

**Cause:** `S3StorageService` was injected into `ReportsController` in a previous session (for S3 cleanup on report delete) but the required `using FieldMind.Api.Services;` directive was never added to the file.

**Fix:** Added the missing using statement.

```csharp
// Added
using FieldMind.Api.Services;
```

### 2. Web job — npm ci lockfile mismatch

**Step:** Install dependencies (`npm ci --ignore-scripts`)

**Cause:** `npm ci` requires `package-lock.json` to exactly match all `package.json` files across all workspaces. New Expo packages (`expo-notifications`, `expo-device`, `expo-constants`) were added to `apps/mobile/package.json` in a previous session but `npm install` was never re-run locally to regenerate the root `package-lock.json`.

**Fix:** Switched from `npm ci` to `npm install --ignore-scripts` in the CI workflow. This tolerates lockfile drift while still skipping native Expo/React Native postinstall scripts that fail on Linux.
